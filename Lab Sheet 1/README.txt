MONGODB / NOSQL LAB SHEET 1

This folder contains 25 separate JavaScript files, one for each question.

IMPORTANT:
1. These are MongoDB Shell (mongosh) scripts, not Node.js programs.
2. Open mongosh, then run one file at a time:
   load("C:/path/to/Question01.js")
   Use the actual path where you saved the file.
3. Run Question01 first, then Question02, and continue in order.
4. Questions 22 and 23 require practical work in MongoDB Compass; their files
   contain the steps/comments to follow.
5. Question 24 is a comparison table in comments.
6. Question 25 is a report checklist. Add your own real screenshots and details.
7. Some questions change or delete data. Run them in sequence on this lab database.
8. Question17 renames Students to StudentDetails. Question18-20 then perform
   collection/database operations. Question21 recreates StudentDB and Students.

To upload to GitHub:
Open the folder, select all files, then upload them into your Lab Sheet 1 folder.
